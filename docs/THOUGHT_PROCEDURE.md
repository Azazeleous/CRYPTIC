# CRYPTIC Thought Procedure

This is an auditable computational procedure, not a claim of consciousness.

For every task:

1. **Parse** — identify the requested outcome, constraints, inputs, and unknowns.
2. **Ground** — retrieve source evidence and record provenance.
3. **Represent** — convert inputs into typed, canonical structures while preserving originals.
4. **Decompose** — create a bounded task graph with dependencies and acceptance criteria.
5. **Hypothesize** — generate candidate explanations or plans with explicit assumptions.
6. **Check** — test mathematical, factual, security, and resource constraints.
7. **Select** — choose the candidate with the strongest evidence and acceptable risk.
8. **Execute** — use only registered capabilities and granted permissions.
9. **Verify** — independently test outputs and invariants.
10. **Learn** — record outcome, error class, remedy, evaluation result, and reusable lesson.
11. **Update** — propose changes to model, memory, or extension registry; promote only after evaluation and approval.
12. **Report** — state result, evidence, uncertainty, limitations, and next action.

Every stage emits a structured record with task ID, input/output digests, timestamps, source references, status, and failure/remedy information. Preserve failed attempts as evidence; do not rewrite history.
