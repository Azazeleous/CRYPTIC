# Threat Model

Assets: source credentials, device identities, user data, model artifacts, training data, storage manifests, runtime integrity, and operator controls.

Threats: malicious extensions, prompt injection, compromised data sources, dependency compromise, credential theft, replay, spoofed chain endpoints, poisoned training data, storage corruption, device impersonation, privilege escalation, and denial of service.

Controls: provenance, signature verification, sandboxing, least privilege, rate limits, schema validation, replay protection, audit logs, immutable backups, anomaly detection, and tested revocation/recovery.
